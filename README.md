# 🧾 Projeto Pessoal: Análise de Vendas com MySQL

Oi! 👋 Esse é o meu primeiro projeto com banco de dados usando MySQL.  
Criei um banco simples de vendas fictícias para treinar os conceitos básicos de SQL.

## 💡 O que tem aqui

- Criação de banco de dados e tabela
- Inserção de dados manuais
- Consultas simples com filtros, ordenação e cálculos
- Tudo feito passo a passo para eu praticar de verdade

## 🛠️ Ferramentas usadas

- MySQL (via terminal)
- VS Code para escrever os comandos 

## 📚 O que eu aprendi

- Sintaxe básica do SQL
- Criar e manipular tabelas
- Fazer consultas com `SELECT`, `WHERE`, `ORDER BY`
- Fazer contas direto na consulta, tipo `quantidade * preco`
